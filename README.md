# Railway Depot Simulator

> A deep simulation of the life cycle of electric trains and railway depots.

## О проекте

Это не обычный train driving simulator.

Проект посвящён моделированию жизненного цикла электропоезда как сложного технического объекта.

Игровая модель строится по принципу:

Train → Car → System → Module → Component

Каждый значимый объект может иметь собственное техническое состояние, пробег, историю ремонтов, неисправности и жизненный цикл.

## Основная идея

Игрок управляет железнодорожным депо:

- формирует составы;
- выпускает поезда на линию;
- проводит диагностику;
- выполняет ремонт;
- управляет запчастями;
- использует вагоны-доноры;
- отправляет технику в другие депо;
- развивает инфраструктуру;
- принимает решения, последствия которых сохраняются в истории объектов.

## Первый этап

Первая версия проекта ориентирована на постсоветскую железнодорожную систему и глубокую симуляцию электропоезда ЭР2Т.

Вместо большого количества поверхностно смоделированных серий основной упор делается на одну серию, смоделированную максимально подробно.

## Текущий статус

Проект находится на стадии концепции и прототипирования.

## Цели проекта

- реалистичная модель технического состояния;
- причинно-следственные неисправности;
- индивидуальная история поездов, вагонов и компонентов;
- физическое железнодорожное депо;
- ремонт и обслуживание;
- управление запасными частями;
- междеповская логистика;
- развитие предприятия;
- живой мир, существующий независимо от игрока.
